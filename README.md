# Home Server
Это файлы персонального домашнего сервера, построенного на базе Raspberry Pi 5.

### Медиа-сервер
В качестве медиа-сервера используется следующий стек программного обеспечения:
- [Plex](https://www.plex.tv/) — для организации и трансляции мультимедиа. Доступен извне по протоколу HTTPS через защищенный туннель.
- [Radarr](https://radarr.video/) — автоматический загрузчик фильмов.
- [Sonarr](https://sonarr.tv/) — автоматический загрузчик сериалов.
- [Seerr](https://seerr.dev/) — современный интерфейс для управления запросами на загрузку контента (мигрировано с Overseerr). Конфигурация перенесена в директорию `Seerr/`.
- [Prowlarr](https://wiki.servarr.com/prowlarr) — индексатор и интегратор для торрент/usenet.

### Дополнительное программное обеспечение
В дополнение к основным медиа-сервисам, в домашнем сервере используются следующие инструменты:
- **Conky** — легковесный мониторинг системы, отображающий на рабочем столе информацию о загрузке CPU, памяти, дисков, сети и др.
- **Portainer** — удобный веб-интерфейс для управления Docker-контейнерами, позволяющий визуально контролировать и конфигурировать сервисы.
- **Glance** — современный дашборд для мониторинга состояния серверных сервисов и вывода ключевых метрик на одну страницу.
- **qBittorrent** — легкий и функциональный торрент-клиент с веб-интерфейсом, используемый для загрузки и управления контентом.
- **nginx** — высокопроизводительный веб-сервер, используемый в качестве локального реверс-прокси.
- **FRP (frpc)** — клиент высокопроизводительного обратного прокси-сервера. Используется для проброса локальных сервисов (Plex, Seerr и др.) в глобальную сеть через VPS с белым IP.

### Архитектура доступа
Доступ к серверу из интернета организован через связку **FRP туннеля** и **Nginx Proxy Manager**, развернутого на внешнем VPS. Это обеспечивает безопасное зашифрованное соединение (HTTPS) и доступ по собственному домену без необходимости открывать порты на домашнем роутере.
